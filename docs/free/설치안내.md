# /free — 감사보고서 무료 변환 퍼널 운영 안내

이 폴더(`docs/`)는 `.vercelignore` 로 배포에서 빠진다 — 공개 주소에 올라가지 않는다.

## 구성

```
free/index.html        01 심플 (대표 · 검색 노출)
free/fancy.html        02 화려          ┐
free/retro.html        03 90년대 복고   │
free/gungseo.html      04 궁서체        │ 검색 제외(noindex) · canonical 은 /free/
free/newspaper.html    05 신문 호외     │
free/terminal.html     06 CRT 터미널    │
free/receipt.html      07 영수증·전표   ┘
free/all.html          디자인 모음(일곱 장 미리보기 · noindex) — 블로그·링크드인 공유용
free/config.js         신청 주소(Apps Script 웹 앱) — 일곱 장이 같이 읽는다. 주소는 여기 한 곳만 고친다
docs/free/Code.gs      구글 시트에 붙인 Apps Script 원본
```

`vercel.json` 의 `cleanUrls` 로 주소에 `.html` 이 붙지 않는다(`.html` 로 들어오면 짧은 주소로 308).

## 신청 흐름

```
/free 페이지 폼 ─▶ Apps Script 웹 앱(사장님 구글 계정)
                    ├─▶ 구글 시트 「감사보고서 변환 신청」 › 「신청」 탭에 한 줄
                    │     신청일시 · 회사명 · 담당자 · 직책 · 이메일 · 연락처 · 유입 페이지 · 상태 · 발송일 · 메모
                    ├─▶ 신청자에게 접수 확인 메일(「3영업일 안에」)
                    └─▶ 사장님께 「[새 신청] 회사명」 알림
```

- 「유입 페이지」 = 페이지마다 숨은 `page` 칸(01 심플 … 07 영수증). 어느 디자인이 신청을 받는지 여기서 센다.
- 필수 항목: 회사명 · 담당자 성명 · 직책 · 이메일 · 연락처(숫자 9자리 이상) · 개인정보 동의 — 페이지와 스크립트 양쪽에서 막는다.
- DART 는 신청 때 조회하지 않는다. 시트를 보고 한 건씩 변환한다(동시 요청 금지 — IP 차단 이력).

## 스크립트를 고쳤을 때

1. `docs/free/Code.gs` 를 고친다.
2. 시트 › 확장 프로그램 › Apps Script 에 통째로 붙여 넣고 저장.
3. 머리줄이 바뀌었으면 `setup` 실행.
4. **배포 › 배포 관리 › 수정(연필) › 버전: 새 버전 › 배포** — URL 은 그대로라 `config.js` 는 안 고쳐도 된다.
   (「새 배포」를 누르면 URL 이 바뀐다 — 그때는 `free/config.js` 를 새 URL 로.)

## 시트 운영

- 「상태」: 접수 → 변환중 → 발송. 「발송일」은 파일을 보낸 날.
- 접수 확인 메일은 스크립트 주인의 Gmail 로 나간다(개인 Gmail 하루 약 100통 한도).

## 남은 일

- 본 페이지 `#apply`(Web3Forms)와 `/free`(Apps Script) 두 곳에서 신청을 받는다 — 하나의 시트·하나의 메일함으로 모을 것.
- 회사 메일(hello@auditfy.co.kr)이 생기면 접수 확인 메일 발신 주소와 바닥글 연락처를 그 주소로.
